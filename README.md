## Sources

- [Unihan](https://www.unicode.org/reports/tr38/): grapheme data
- [SUBTLEX-CH](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0010729): frequency data
- [Make Me a Hanzi](https://github.com/skishore/makemeahanzi): stroke data
- [Hanzi Writer](https://github.com/chanind/hanzi-writer): javascript widget for practicing strokes
- [Complete HSK Vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary): for mapping characters that happen to be words to HSK level
